## 🤝 Contributing to Documentation

Found a typo? Want to add a section? Contributions welcome!

**Guidelines**:
- Follow [Markdown Conventions](DOCUMENTATION-SUMMARY.md#markdown-conventions)
- Use [Mermaid](https://mermaid.js.org/) for diagrams
- Add screenshots to `images/` directory
- Cross-reference related sections
- Test all code snippets before committing

**Standards**:
- 📁 **File Naming**: `kebab-case.md`
- 🎨 **Color Scheme**: Domain 🟢, Application 🔵, Infrastructure 🟠, Presentation 🟣
- 📖 **Structure**: TOC → Sections → Examples → Cross-Links
