## Image Optimization
Before adding images:
1. Compress with TinyPNG or ImageOptim
2. Create @2x versions for retina displays
3. Generate WebP versions for modern browsers
4. Target sizes:
   - Hero: < 500KB
   - Feature images: < 200KB
   - Icons: SVG (< 5KB each)
